# 声句工坊使用手册（P10）

本版覆盖录音整理、v4 微调、模型导出、文本合成和作品库。逐阶段的实际验证范围见 `ACCEPTANCE_REPORT.md`。2026-11-18 已按用户指令恢复实施；句子回流与二次微调、最终 Windows 双击启停及全新环境验证分别留在 P11、P12。

## 在当前机器运行

在 PowerShell 中执行：

```powershell
Set-Location E:\DictionForge
$env:PYTHONPATH = 'E:\DictionForge\backend'
& .\.venv-api\Scripts\python.exe -m dictionforge.serve
```

然后打开 `http://127.0.0.1:7867`。这是前端生产构建的同源本机服务。模型 worker 使用独立的 `.venv-worker`，数据根目录默认 `E:\DictionForge\data`。如果修改前端，先在 `frontend` 目录执行 `pnpm run build`。

需要停止时，先等待合成结束或将训练安全暂停，再在另一个 PowerShell 中执行：

```powershell
Invoke-RestMethod -Method Post http://127.0.0.1:7867/api/system/stop
```

仍有排队或运行任务时服务会拒绝停止。不要直接关闭有活动训练的进程。P12 将补齐面向最终用户的双击启动和停止脚本；当前环境的 Python 基础解释器仍依赖已有本机路径，迁移机器请先看 `CODEX_HANDOFF.md`。

## 从角色录音到数据版本

在「微调训练」页选择角色录音目录，填写角色名并扫描。源录音只读，扫描结果可试听和排除。支持同名 `.lab` 文本快照；切成多个片段后不能把整段文本直接复制到每片。

设置切分长度、静音阈值并整理。ASR 使用锁定的本地中文模型，实际运行在 GPU；当前开放已验证的普通话。逐段校对文字、试听、排除无用片段并确认审核，再发布不可变数据版本。重识别、校对和发布使用修订号，旧页面的过期更新会被拒绝。

数据版本可继续建立新草稿；旧版本保留。原始录音分组决定留出集，避免同一录音被切开后同时进入训练和验证。准备特征时实际运行文本/BERT、HuBERT/32k 音频、语义三段上游处理，未改变的样本可复用校验后的缓存。

## 预检、训练和恢复

选数据版本、训练阶段和参数后运行预检。预检真正加载 S1/S2 数据并检查非空批次；不能把「文件存在」当作可训练。当前新训练初始化使用官方底模，来源模型初始化与新数据回流会在 P11 接通验证。

SoVITS v4 使用 LoRA，随后 GPT 微调。后台显示实际优化器更新、loss、学习率、阶段交接和显存；模型加载等未知总量过程不显示虚构百分比。训练、ASR、特征和合成共用独占 GPU 队列。

「暂停」等待梯度累积周期和优化器安全边界，保存完整检查点后才显示 PAUSED。「继续」复用同一冻结数据、配置和累计目标；更换数据或配置应建立新运行。检查点包含优化器、调度器、精度状态、随机状态和采样游标。可以从兼容的历史恢复点派生独立运行。损坏点和最后有效点分别报告，不会静默回到底模。

「导出并继续」冻结权重快照后在 CPU 队列校验发布，GPU 训练继续。「中止并导出」结束后续训练，保留完整恢复点及可推理权重对。正常完成自动发布，失败可以从同一快照重试。某阶段尚未训练时，模型卡明确显示该阶段使用初始权重。

## 模型、参考和对比

模型版本包含 GPT `.ckpt`、SoVITS v4 LoRA `.pth`、底模依赖、训练来源和哈希。结构校验与 GPU 试听结果分别展示。外部导入仅使用您信任的本地权重对，并需明确勾选受信任；不要加载来源不明的 pickle 权重。

在「语音合成」页选择模型，导入或上传 3–10 秒、带准确文本的单声道参考。应用制作独立的 48k 单声道副本并保留来源哈希。设置默认参考后可启用模型；启用是逻辑选择，实际 GPU 驻留仅在 worker 加载时出现。

固定条件比较会让所选模型和官方底模使用同一冻结参考、短句和参数。排队期间修改默认参考不改变已受理任务；新的参考需要独立试听验证。这里的自动解码及播放验收不代表主观音色评价。

## 文本合成和逐句播放

选择可用模型与参考，输入中文文本，设置语速并开始。高级选项提供按标点、按行或不分句，及种子、采样步数、top-k、top-p、温度等参数。每个请求冻结原文、模型权重哈希、参考音频与文本、实际参数。页面输入修改只影响下一条请求。

一个任务内按文本顺序生成各句，再直接拼接为原生 48 kHz 单声道 WAV。每句有独立 ID、独立 WAV、原文 Unicode 字符范围、整段样本范围及实际种子；重复句各自有 ID。点击句子可以定位播放，播放器同步显示当前句；刷新后从服务端恢复当前结果。

「上游片段间隔」直接传给锁定的上游实现；v4 的最终静音时长可能不同于该参数值（本机参数 0.3 实测约 0.2 秒）。结果以真实样本区间为准，不额外裁切或添加静音。

空白、仅标点、非法控制字符、未支持语言或超限参数会返回错误，并保留当前结果。具体失败可在后台任务和日志查看模型加载、参考处理、文本前处理或句子编号。显存不足不会静默降参重试。

成功结果可填写标题并保存 WAV 或 320 kbps MP3。保存任务会制作独立文件，完成后进入「已保存语音」，可跨重启播放和下载。MP3 作品同时保留独立无损源。当前没有「加入数据集」功能；P11 会基于不可变逐句索引实施回流。

有效新合成受理后，旧临时音频在播放、保存等引用释放后回收。无效请求保留当前结果；取消任务会释放其临时音频。历史任务仍可查看原文和状态，已回收的音频显示失效。需要保留的结果请先保存为作品；打开播放器期间音频受保护，关闭播放器后允许回收。Windows 文件占用会进入待清理，释放占用后自动重试。

## 已保存语音

作品按创建时间倒序显示，每页最多 10 件。可按来源模型、标题或正文筛选，打开播放器试听，或直接下载原保存格式。永久作品不依赖临时合成目录。

删除支持单件、全选本页和当前筛选的全部结果。先点击预览，核对确切标题、ID 和件数，再确认删除。预览后新增加的作品不进入该次删除集合。切换筛选或翻页会清除选择；正在播放或被任务使用的作品会保留并显示原因，关闭播放器后可重新预览删除。

## 文件与数据保护

`data/state` 保存 SQLite 状态；`data/runs/<任务 ID>` 保存日志及训练产物，`data/runtime/tts/<任务 ID>` 保存合成请求和音频。`data/`、`vendor/`、虚拟环境及前端构建不进入 Git，下一次继续前应保留这些目录。不要只备份代码而丢掉本机模型和录音副本。

删除模型或数据版本先展示精确预览；被活动任务、恢复点、派生关系或参考使用的记录受到保护。应用只管理自己的产物，原始录音与 TimbreForge 保持只读。排障见 `TROUBLESHOOTING.md`，续做信息见 `CODEX_HANDOFF.md`。
