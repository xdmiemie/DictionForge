# 声句工坊使用手册（P12）

本版覆盖录音整理、v4 微调、模型导出、文本合成和作品库。逐阶段的实际验证范围见 `ACCEPTANCE_REPORT.md`。P00–P12 已完成，包含句子回流、来源模型二次微调、独立环境与 Windows 启停。

2026-11-18 后续界面更新：工作区分为「微调训练」「语音合成」「数据与模型管理」。记录列表每页最多 5 项，使用「上一页 / 下一页」；原生下拉框可滚动选择。文字审核每次显示一条，标注总览每页 5 条。翻页保留校对和排除状态，播放或定位到另一页的句子时自动显示当前句。

## 安装、启动和停止

首次下载代码后，双击根目录「准备DictionForge.cmd」。它把固定版本的 Python、uv、Node、pnpm、Git、FFmpeg 放入项目自己的 vendor/tools，创建独立 API/worker 环境、构建前端、准备模型资产并执行诊断。首次准备需要网络、NVIDIA 驱动与足够磁盘；本机已完成准备，可直接启动。无需安装或修改 TimbreForge，也不改变系统 PATH。

双击「启动DictionForge.cmd」，浏览器自动打开 http://127.0.0.1:7867 。重复启动复用同一工作区实例；命令窗口返回后后台服务继续运行。正在运行或排队的任务会阻止停机；先在页面安全暂停训练或等待任务完成，再双击「停止DictionForge.cmd」。不会强杀其他端口或其他工作区的服务。

脚本支持任意当前目录。PowerShell 的等效调用：

```powershell
& 'E:\DictionForge\scripts\setup.ps1' -Worker -Assets
& 'E:\DictionForge\scripts\doctor.ps1' -Assets
& 'E:\DictionForge\scripts\start.ps1'              # 自动打开浏览器
& 'E:\DictionForge\scripts\start.ps1' -NoBrowser   # 复用或后台启动
& 'E:\DictionForge\scripts\stop.ps1'
```

应用只绑定本机；默认数据目录为 E:\DictionForge\data。需要更换端口时，对 start/stop 都传相同的 -Port；同一数据目录只能有一个服务实例。重建环境前停止服务，使用 setup.ps1 -Worker -Recreate，原环境与前端依赖会备份到项目目录。离线重放可传 -Offline -Wheelhouse E:\DictionForge\data\wheelhouse，需要事先准备工具包、Python依赖、pnpm store、上游源码和模型资产；新机器没有缓存时按正常联网准备。

服务日志在 data/logs，任务日志在 data/runs。模型大文件不在 Git 中，迁移时需重新执行资产准备，或保留完整 data/vendor 及其路径关系；不要只复制检查点而遗漏数据库、对应模型和数据版本。

## 从角色录音到数据版本

在「微调训练」页选择角色录音目录，填写角色名并扫描。输入可以只有语音文件，无需提前准备文字。源录音只读，扫描结果可试听和排除。已有同名 `.lab` 时仍兼容读取；切成多个片段后不能把整段文本直接复制到每片。

设置切分长度、静音阈值并整理。STT / ASR 使用锁定的本地中文模型，把每段语音识别为微调所需的文字，实际运行在 GPU；当前开放已验证的普通话。

整理完成后在「文字审核窗口」选择：

- 「开始逐条审核」：每次显示一段音频及识别文字，可修正文案。点击「通过，下一条」自动保存并进入下一条；点击「去掉数据，下一条」保存排除决定并进入下一条。去掉不会删除原始录音。
- 「跳过审核，全部默认通过」：将保留片段全部标记通过并保存，随后点击「确认并发布数据版本」。
- 审核中点击「结束审核，剩余默认通过」：保留已修正文字和排除决定，将剩余片段默认通过并保存。也可通过「全部标注与审核状态」重新查看某条。

识别失败且文字为空的片段不能组成有效训练样本，窗口会定位到该条，需补写、重新识别或去掉后再通过。重识别、校对和发布使用修订号，旧页面的过期更新会被拒绝。审核动作完成后标注即落盘；仅输入而未点击通过的改字仍属于未保存修改。

数据版本可继续建立新草稿；旧版本保留。原始录音分组决定留出集，避免同一录音被切开后同时进入训练和验证。准备特征时实际运行文本/BERT、HuBERT/32k 音频、语义三段上游处理，未改变的样本可复用校验后的缓存。

## 预检、训练和恢复

选数据版本、训练阶段和参数后运行预检。预检真正加载 S1/S2 数据并检查非空批次；不能把「文件存在」当作可训练。新训练可选择官方底模或已验证模型：GPT 载入选定权重，SoVITS 载入锁定底模与来源 LoRA，rank 必须兼容。预检冻结实际权重哈希；新训练从零建立优化器，不继承来源模型的训练计数。

SoVITS v4 使用 LoRA，随后 GPT 微调。后台显示实际优化器更新、loss、学习率、阶段交接和显存；模型加载等未知总量过程不显示虚构百分比。训练、ASR、特征和合成共用独占 GPU 队列。

「暂停」等待梯度累积周期和优化器安全边界，保存完整检查点后才显示 PAUSED。「继续」复用同一冻结数据、配置和累计目标；更换数据或配置应建立新运行。检查点包含优化器、调度器、精度状态、随机状态和采样游标。可以从兼容的历史恢复点派生独立运行。损坏点和最后有效点分别报告，不会静默回到底模。

「导出并继续」冻结权重快照后在 CPU 队列校验发布，GPU 训练继续。「中止并导出」结束后续训练，保留完整恢复点及可推理权重对。正常完成自动发布，失败可以从同一快照重试。某阶段尚未训练时，模型卡明确显示该阶段使用初始权重。

## 模型、参考和对比

「数据与模型管理」页面集中展示模型版本、已发布数据版本和整理后的标注草稿。点击「查看删除范围」立即弹出对话框，读取并列出本次对象、关联对象、具体文件和总大小；对象和文件列表每页最多 5 项。点击「确认删除此模型版本及关联记录」（或数据版本、草稿）后，一并删除预览范围内的内容，不能撤销。取消或按 Esc 可关闭，读取或确认失败时原因显示在框内。

删除范围会递归包含依赖它的派生模型、数据版本、标注草稿、回流记录、训练任务及完整恢复点、导出快照、临时合成和试听记录等；已启用模型会同时清除启用状态。历史引用与暂停训练不再单独阻止删除，但删除恢复点后无法续训。只删除模型时，不因它曾使用某个上游数据版本就删除该上游版本；最终以预览中的关联对象和文件为准。原始录音、共享官方底模、独立保存的语音作品及未列入范围的借用音频保留。

运行中或排队的关联任务，以及正在下载或复制文件的操作仍会阻止删除；待完成或安全暂停训练后重新查看范围。普通播放器引用可随确认关闭。确认时会重新核对关联集合、记录内容与文件哈希；预览后新增关联、修改数据或产生新文件时，旧确认会被拒绝，需要重新查看范围。不要绕过页面直接删除目录。

模型版本包含 GPT `.ckpt`、SoVITS v4 LoRA `.pth`、底模依赖、训练来源和哈希。结构校验与 GPU 试听结果分别展示。外部导入仅使用您信任的本地权重对，并需明确勾选受信任；不要加载来源不明的 pickle 权重。

在「语音合成」页选择模型，导入或上传 3–10 秒、带准确文本的单声道参考。应用制作独立的 48k 单声道副本并保留来源哈希。设置默认参考后可启用模型；启用是逻辑选择，实际 GPU 驻留仅在 worker 加载时出现。

固定条件比较会让所选模型和官方底模使用同一冻结参考、短句和参数。排队期间修改默认参考不改变已受理任务；新的参考需要独立试听验证。这里的自动解码及播放验收不代表主观音色评价。

## 文本合成和逐句播放

选择可用模型与参考，输入中文文本，设置语速并开始。高级选项提供按标点、按行或不分句，及种子、采样步数、top-k、top-p、温度等参数。每个请求冻结原文、模型权重哈希、参考音频与文本、实际参数。页面输入修改只影响下一条请求。

一个任务内按文本顺序生成各句，再直接拼接为原生 48 kHz 单声道 WAV。每句有独立 ID、独立 WAV、原文 Unicode 字符范围、整段样本范围及实际种子；重复句各自有 ID。点击句子可以定位播放，播放器同步显示当前句；刷新后从服务端恢复当前结果。

「上游片段间隔」直接传给锁定的上游实现；v4 的最终静音时长可能不同于该参数值（本机参数 0.3 实测约 0.2 秒）。结果以真实样本区间为准，不额外裁切或添加静音。

空白、仅标点、非法控制字符、未支持语言或超限参数会返回错误，并保留当前结果。具体失败可在后台任务和日志查看模型加载、参考处理、文本前处理或句子编号。显存不足不会静默降参重试。

成功结果可填写标题并保存 WAV 或 320 kbps MP3。保存任务会制作独立文件，完成后进入「已保存语音」，可跨重启播放和下载。MP3 作品同时保留独立无损源。从当前逐句结果可以直接追加到来源角色的数据集。

有效新合成受理后，旧临时音频在播放、保存等引用释放后回收。无效请求保留当前结果；取消任务会释放其临时音频。历史任务仍可查看原文和状态，已回收的音频显示失效。需要保留的结果请先保存为作品；打开播放器期间音频受保护，关闭播放器后允许回收。Windows 文件占用会进入待清理，释放占用后自动重试。

## 已保存语音

作品按创建时间倒序显示，每页最多 5 件。可按来源模型、标题或正文筛选，打开播放器试听，或直接下载原保存格式。永久作品不依赖临时合成目录。

删除支持单件、全选本页和当前筛选的全部结果。先点击预览，核对确切标题、ID 和件数，再确认删除。预览后新增加的作品不进入该次删除集合。切换筛选或翻页会清除选择；正在播放或被任务使用的作品会保留并显示原因，关闭播放器后可重新预览删除。

## 文件与数据保护

`data/state` 保存 SQLite 状态；`data/runs/<任务 ID>` 保存日志及训练产物，`data/runtime/tts/<任务 ID>` 保存合成请求和音频。`data/`、`vendor/`、虚拟环境及前端构建不进入 Git，下一次继续前应保留这些目录。不要只备份代码而丢掉本机模型和录音副本。

删除模型或数据版本先展示精确预览；被活动任务、恢复点、派生关系或参考使用的记录受到保护。应用只管理自己的产物，原始录音与 TimbreForge 保持只读。排障见 `TROUBLESHOOTING.md`，续做信息见 `CODEX_HANDOFF.md`。

## 当前句回流与二次微调

在当前结果选择一句，核对目标角色和切分规则后点击「将当前句加入数据集」。完整一句复用原文本；切为多片则逐段执行 ASR，必须分别校对和确认，或排除不合格片段，再点击「准备特征并发布回流版本」。短于规则的区间会列出，截断残片请排除，不能给每片复制整句文本。

新增数据和三段特征完整后才发布新版本。父版本与真实留出集保持不变，合成片段只进训练集；并发追加会基于最新后继合并，相同内容不重复。失败保留草稿，可修正后重试，后台任务显示具体阶段和日志。受理后的追加任务持有源音频，后续新合成不破坏正在处理的追加。

完成后点击「用新版本微调」，训练页预选新数据和来源模型；也可改为「官方底模」。重新预检后提交新训练。与暂停续训不同，这会创建新优化器和从零开始的计数。没有角色数据归属的外部模型或官方模型生成结果不能自动推断回流目标，页面说明原因。
